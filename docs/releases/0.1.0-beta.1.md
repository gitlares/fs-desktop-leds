# FS Desktop LEDs 0.1.0-beta.1

The first public beta puts desk lighting in the Mac menu bar: colors, 14 scenes,
six animations, screen-based Ambient lighting and sound-reactive modes.

- Native cascading menus, with brightness and timing controls inside each mode.
- System audio or microphone input, frequency colors and beat-driven color changes.
- Optional notification flashes that restore the previous lighting state.
- English and Spanish, following the system language.
- Manual signed updates through Sparkle; no telemetry or system-profile reporting.
- Normal quit requests lights off before disconnecting.

## Install

Download the DMG, open it, and drag Desktop LEDs to Applications. This build is
for Apple Silicon and macOS 14 or later. The app and DMG are Developer ID signed
and Apple notarized. SHA256SUMS covers both the DMG and the updater ZIP.

## Beta limitations

The tested hardware is ELK-BLEDOM using the alternate protocol. Colors, brightness
and software-driven whole-strip effects have been tested on that controller.
Individual LED addressing and other controllers are unverified. Hardware firmware
fade commands did not produce visible effects on the tested unit.

Music response needs testing across more audio sources. Notification detection is
experimental: it uses visible macOS banners, may miss notifications and cannot
see alerts hidden by Focus. Force quit or loss of Bluetooth cannot guarantee
that the lights turn off. This beta was tested on macOS 26.7; macOS 14 is the
build's minimum deployment target, not a claim of hardware validation there.
