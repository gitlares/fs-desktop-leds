# FS Desktop LEDs 0.1.0-beta.2

This public beta adds native support for **BJ_LED_M / MohuanLED** Bluetooth LED
controllers, alongside ELK-BLEDOM.

- BJ_LED_M controllers are detected automatically and use their `EE02` BLE
  channel.
- Power and full-strip RGB use the documented MohuanLED packet format.
- Brightness is applied by scaling RGB, matching the reference protocol.
- The compatibility page and README now identify both supported controller
  families.

## Compatibility

The driver was validated with a BJ_LED_M strip controlled by BojiaLed. Both
supported families currently apply a single RGB color to the whole strip;
individual LED pixels and independent segments are not exposed by these
protocols. For a more blended ambient effect, point the strip at a wall or use
an opal diffuser.

## Install

Download the DMG, open it, and drag Desktop LEDs to Applications. This build is
for Apple Silicon and macOS 14 or later. The app and DMG are Developer ID signed
and Apple notarized. SHA256SUMS covers both the DMG and the updater ZIP.
